# Consulta por código de barras

Objetivo: consultar nutrientes no Open Food Facts, revisar o rótulo e salvar no catálogo local antes de adicionar uma quantidade ao diário.

Arquitetura: componente cliente separado, consulta pública direta sem credenciais, adaptador testável em lib/barcode.js e integração com addCustomFood existente. A câmera usa BarcodeDetector quando disponível; a digitação permanece disponível. Sem mudança no armazenamento ou banco externo.

- [x] Validar GTIN com dígito verificador e preservar zeros iniciais.
- [x] Mapear os valores por 100 g/ml; deixar nutrientes ausentes vazios e exigir confirmação da unidade.
- [x] Revisar e salvar usando a validação existente; calcular porção ao adicionar ao diário.
- [x] Tratar produto ausente, erro de rede e câmera sem suporte/permissão; cancelar consultas e liberar câmera ao fechar.
- [x] Validar testes de domínio, build/TypeScript e fluxo móvel em navegador com API controlada.

Limites: leitura óptica depende de HTTPS, permissão e suporte a BarcodeDetector. A API pública depende de acesso a world.openfoodfacts.org. Testes com respostas controladas não substituem validação do serviço externo nem de câmera física.

Verificação: 49 testes passaram; build e TypeScript passaram; teste móvel em Chromium passou com API controlada, incluindo câmera simulada e liberação dos tracks. Consulta real bloqueada por HTTP 403 do proxy; domínio salvo no rascunho da configuração, ainda dependente de aplicação/publicação.
